# Infrastructure Investment Lab

A self-contained research prototype: a project's prerequisites mapped and priced in equity value, read through S³, with the public CHPE (Champlain Hudson Power Express) case and a pre-registered alpha test.

The whole application is the single file `index.html`. It needs no server, no build step and makes no network requests. Figures are model arithmetic under stated assumptions, not forecasts; no investment alpha is claimed.

Published with GitHub Pages from the `main` branch of this repository.
